# Uz Yangi O‘zbek Alifbosi (2026) – Rasmiy Windows Klaviaturasi

Yangi tasdiqlangan o'zbek lotin alifbosi (**Ğ, Ş, Ö, Ç**) harflarini Windows tizimida qulay va xatosiz yozish uchun ishlab chiqilgan rasmiy klaviatura terilmasi (Layout). 

Bu dastur fon rejimida ishlab kompyuterni qotirmaydi — u to'g'ridan-to'g'ri Windows tizimining til paneliga (`ENG / UZB`) rasmiy til klaviaturasi bo'lib o'rnashadi.

## ⚙️ O'rnatish jarayoni
1. O'ng tomondagi **[Releases](https://github.com/SizningUzeringiz/Uzbek-Latin-Keyboard-2026/releases)** bo'limidan eng so'nggi `.zip` faylni yuklab oling.
2. Arxivni ochib, ichidagi `setup.exe` faylini ishga tushiring.
3. 1-2 soniyadan so'ng o'rnatish yakunlanadi. Ekraningizning pastki o'ng burchagidagi tillar panelidan **"Uzbek (Latin) - O'zbek (Yangi Lotin - 2026)"** ni tanlang.

## ⌨️ Tugmalar joylashuvi
Yangi harflar eng qulay va standart joylashuvga (Ruscha X, Ъ, Ж, Э) biriktirilgan:

| Klaviatura tugmasi | Kichik harf | Katta harf (Shift / CapsLock) |
| :--- | :---: | :---: |
| `[` (X o'rni) | **ğ** | **Ğ** |
| `]` (Ъ o'rni) | **ş** | **Ş** |
| `;` (Ж o'rni) | **ö** | **Ö** |
| `'` (Э o'rni) | **ç** | **Ç** |
| `` ` `` (Tab tepasida) | **’** (Tutuq) | |

### Asl qavslar va tinish belgilarini qanday yozamiz?
Yangi harflar ostida qolib ketgan qavslar (`[`, `]`) va belgilarni (`;`, `'`) yozish uchun **O'ng Alt (AltGr)** tugmasidan foydalaniladi.
* **O'ng Alt + `[`** = `[`
* **O'ng Alt + `]`** = `]`

## 🔬 Olimlar, Muhandislar va Ofis xodimlari uchun (AltGr)
Klaviaturaga ilmiy izlanishlar, slaydlar va rasmiy hujjatlar uchun eng ko'p ishlatiladigan maxsus belgilar qo'shilgan. Ular **O'ng Alt (AltGr)** tugmasi orqali yoziladi:

**Ilmiy va Matematik belgilar:**
* O'ng Alt + **D** ➔ **°** (Gradus)
* O'ng Alt + **M** ➔ **µ** (Mikro)
* O'ng Alt + **A, B, G, L** ➔ **α, β, γ, λ** (Grek harflari)
* O'ng Alt + **2** yoki **3** ➔ **², ³** (Kvadrat, kub)
* O'ng Alt + **=** ➔ **±** (Plyus-minus)

**Ofis va Moliya:**
* O'ng Alt + **N** ➔ **№** 
* O'ng Alt + **-** ➔ **—** (Uzun tire)
* O'ng Alt + **S** ➔ **§** (Paragraf)
* O'ng Alt + **4** ➔ **$**
